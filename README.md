# Personal Expense Tracker

A more dynamic React-based personal expense tracker that works completely without a backend. Data is stored locally in the browser.

## Added dynamic features

- Add, edit, and delete expenses
- Payment method and notes for each expense
- Monthly budget with progress tracking
- Spending insights: top category, largest expense, and average transaction
- Search across descriptions, categories, and notes
- Category and payment-method filters
- Date-range filtering
- Sort by newest, oldest, highest amount, or lowest amount
- CSV export of the current filtered report
- JSON backup and restore
- Clear-all data option with confirmation
- Light/dark mode saved in localStorage
- Responsive dashboard and expense table

## Storage

No backend or database is required. Expenses and settings are stored in browser localStorage.

## Run

```bash
npm install
npm start
```
